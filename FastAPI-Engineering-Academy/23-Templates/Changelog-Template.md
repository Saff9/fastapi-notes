# Changelog Template

Use this for tracking material revisions to the vault. Keep entries dated and brief.

```markdown
# Changelog

## [Unreleased]

### Added
- Lesson: <name> — <folder/Note>

### Changed
- <Lesson>: <what changed and why>

### Fixed
- <Lesson>: <broken link / incorrect API / etc.>

### Removed
- <Lesson>: <reason>

## [2026-10-19]

### Added
- Initial vault: directory structure, spine files, Phase 1 lessons.

### Known Limitations
- <lesson> is a stub; content still being drafted.
- Mermaid diagrams in <lesson> not verified against a renderer.
```

Append to the existing changelog at `21-Reference-Library/Changelog.md` (or create it on first revision). Do not rewrite history.
